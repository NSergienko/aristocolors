# @aristocolors/config

Спільні конфігураційні пакети для середовища AristoColors Monorepo:

- **TypeScript:** Базовий (`./typescript/base`), для Node.js 22 LTS (`./typescript/node`), для React 19 (`./typescript/react`).
- **ESLint:** Базові правила типізації (`./eslint/base`).
- **Prettier:** Конфігурація форматування коду (`./prettier`).
- **Tailwind:** Пресет дизайн-системи AristoColors (`./tailwind`).
